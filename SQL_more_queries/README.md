MySQL - Advanced SQL
In this project, I am deepening my understanding of relational database management using MySQL. By the completion of these tasks, I will be able to manage users, configure complex permissions, and perform advanced data retrieval using subqueries and joins without external assistance.
Learning Objectives
At the end of this project, I am expected to be able to explain to anyone, without the help of Google:
General
How to create a new MySQL user.
How to manage privileges for a user to a database or table.
What's a PRIMARY KEY and its role in unique identification.
What's a FOREIGN KEY and how it links tables together.
How to use NOT NULL and UNIQUE constraints to ensure data integrity.
How to retrieve data from multiple tables in one request.
What subqueries are and how to implement them.
What are JOIN and UNION, and when to use each.
Requirements
General
Allowed editors: I will use vi, vim, or emacs.
Execution Environment: All my files will be executed on Ubuntu 20.04 LTS using MySQL 8.0 (version 8.0.25).
File Formatting:
All my files will end with a new line.
I will ensure all my SQL queries have a comment just before the syntax.
Each of my files will start with a comment describing the task.
I will write all SQL keywords in UPPERCASE (e.g., SELECT, WHERE).
