JavaScript — Fundamentals
Description

In this project, I learned the fundamentals of JavaScript programming using Node.js. The focus was on understanding core language concepts rather than frameworks or browser-based features. Through a series of scripts, I practiced writing executable JavaScript files, managing variables, controlling program flow, and building reusable functions. This project strengthened my ability to reason about program behavior and write clean, standards-compliant code in a Linux environment.

Learning Objectives

At the end of this project, I am able to explain, without external resources:

General
Why JavaScript programming is powerful and widely used
How to run a JavaScript script using Node.js
How to create variables and constants
The differences between var, let, and const
The available data types in JavaScript
How to use conditional statements (if, if...else)
How to write and use comments
How to assign values to variables
How to use while and for loops
How to use break and continue
What functions are and how to use them
What a function returns when no return statement is provided
Variable scope in JavaScript
Arithmetic operators and their usage
How to manipulate objects (dictionaries)
How to import and use modules/files
