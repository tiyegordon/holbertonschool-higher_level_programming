SQL - Introduction to Databases
Project Overview
This project serves as a foundational introduction to Relational Databases and SQL (Structured Query Language). Through this series of tasks, I will explore how to manage data using MySQL 8.0, covering everything from database creation and table manipulation to complex data retrieval and modification.

Learning Objectives
By the end of this project, I will be able to explain the following concepts without external assistance:

General
Databases: What they are and why we use them.

Relational Databases: Understanding structured data and relationships.

SQL: What "Structured Query Language" is used for.

MySQL: Specifics of this popular open-source relational database management system.

Database Management: How to create databases and tables.

Language Categories: Defining DDL (Data Definition Language) and DML (Data Manipulation Language).

CRUD Operations: How to SELECT, INSERT, UPDATE, and DELETE data.

Advanced Querying: Implementing subqueries and utilizing MySQL functions.

Requirements
General Specifications
Environment: All files will be executed on Ubuntu 22.04 LTS using MySQL 8.0.25.

Editors: Allowed editors include vi, vim, and emacs.

Formatting: * All files must end with a new line.

SQL keywords must be in UPPERCASE (e.g., SELECT, FROM, WHERE).

Each file must start with a comment describing the task.

Each SQL query must be preceded by a comment explaining its syntax/purpose.

Validation: File length will be verified using the wc command.
