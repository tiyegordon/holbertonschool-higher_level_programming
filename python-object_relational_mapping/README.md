Python - Object-Relational Mapping
In this project, I am bridging the gap between two powerful worlds: Databases and Python!
In the first phase, I will use the MySQLdb module to connect directly to a MySQL database and execute raw SQL queries. In the second phase, I will transition to using SQLAlchemy, an Object-Relational Mapper (ORM). This transition allows me to abstract the storage layer entirely—focusing on Python objects rather than raw SQL syntax—making my code cleaner and storage-independent.
Learning Objectives
By the end of this project, I will be able to explain the following concepts without the help of Google:
General
How to connect to a MySQL database from a Python script.
How to SELECT rows in a MySQL table using Python.
How to INSERT rows into a MySQL table using Python.
What ORM means and its advantages in software development.
How to map a Python Class to a MySQL table using SQLAlchemy.
