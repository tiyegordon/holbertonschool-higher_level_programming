Project: JavaScript - DOM & Data Fetching
This project focuses on the core principles of modern web development: manipulating the Document Object Model (DOM) and communicating with servers asynchronously. By the end of this module, you will be able to build dynamic, responsive web interfaces that handle data without page reloads.

🎯 Learning Objectives
By the completion of this project, you should be able to explain the following concepts clearly:

DOM Manipulation
Element Selection: Techniques for selecting HTML elements using JavaScript.

Selectors: Understanding the critical differences between ID, class, and tag name selectors.

Style Modification: How to dynamically update the CSS of an HTML element.

Content Management: Methods for getting and updating the text or HTML content within an element.

Structural Changes: How to add, remove, or modify elements within the DOM tree.

Data & Events
Asynchronous Requests: * Making requests using the traditional XmlHTTPRequest.

Making modern requests using the Fetch API.

Event Handling: How to listen and bind to both DOM-specific events and direct user interactions (clicks, inputs, etc.).

🛠 Requirements
Environment
Browser: All files will be interpreted on Chrome (version 57.0 or later).

Editors: You are free to use any code editor of your choice.

Code Style & Standards
Standardization: Your code must be semistandard compliant.

Variables: The use of var is strictly prohibited. Use let or const instead.

Formatting: All files must end with a new line.

Single Page Behavior: HTML must not reload for actions. All updates (fetching data, DOM manipulation) must happen dynamically.
